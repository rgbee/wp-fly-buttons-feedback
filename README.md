# RGBee Fly Buttons Feedback

![WordPress](https://img.shields.io/badge/WordPress-6.0%2B-blue)
![Version](https://img.shields.io/badge/Version-1.2.1-green)

Плагин WordPress для добавления плавающих кнопок обратной связи на сайт. Кнопки включают ссылки на социальные сети (WhatsApp, Telegram, Viber) и формы обратной связи.

## Возможности

### Социальные сети
- WhatsApp с предустановленным текстом сообщения
- Telegram с кастомной ссылкой
- Viber с номером телефона

### Кнопки обратной связи
- Заказать звонок
- Написать сообщение  
- Оставить отзыв

### Настройки для каждой кнопки
- Включение/выключение отображения
- Кастомный заголовок (title)
- Настраиваемая ссылка
- Дополнительные HTML атрибуты
- Кастомные CSS классы
- Индивидуальные цвета

### Особенности
- Локальная версия Font Awesome 6.2.1 для быстрой загрузки
- Полная независимость от CDN
- Настройка цветов и стилей
- Адаптивный дизайн

## Установка

1. Скачайте архив плагина
2. В админ-панели WordPress перейдите в «Плагины» → «Добавить новый»
3. Загрузите архив через «Загрузить плагин»
4. Активируйте плагин «RGBee Fly Buttons Feedback»

## Настройка

После активации перейдите в «Настройки» → «Fly Buttons» для конфигурации:

### Социальные сети
- **WhatsApp**: укажите номер телефона и текст сообщения
- **Telegram**: укажите ссылку на профиль и заголовок
- **Viber**: укажите номер телефона

### Кнопки обратной связи
Для каждой кнопки доступны:
- **Включение/выключение** - чекбокс активации
- **Заголовок** - текст при наведении курсора
- **Ссылка** - URL для перехода (можно использовать # для модальных окон)
- **Атрибуты** - дополнительные HTML атрибуты (например, для модальных окон)
- **CSS класс** - дополнительные классы для стилизации

### Стили
Настройте цвета для:
- Иконок по умолчанию
- Состояния при наведении
- Каждого типа кнопок индивидуально

## Примеры использования

## CSS классы
Плагин использует следующие CSS классы по умолчанию:

- `.fly_buttons` - основной контейнер
- `.fly_item` - элемент кнопки
- `.wa` - WhatsApp кнопка
- `.tg` - Telegram кнопка  
- `.vb` - Viber кнопка
- `.call-btn` - кнопка "Заказать звонок"
- `.message-btn` - кнопка "Написать сообщение"
- `.review-btn` - кнопка "Оставить отзыв"

## Мобильная версия

На мобильных устройствах кнопки автоматически перестраиваются в горизонтальную панель в нижней части экрана.

## Требования

- WordPress 5.0+
- PHP 7.4+

## Технические особенности

- Font Awesome 6.2.1 включен локально в плагин
- Автоматическое создание необходимых папок при активации
- Fallback на CDN если локальные файлы отсутствуют
- Оптимизированная загрузка ресурсов

## Поддержка

Плагин корректно работает с большинством современных тем WordPress. Для кастомной стилизации используйте предоставленные CSS классы и настройки цветов.
