# Changelog

## [1.4.0] - 2026-09-08
### Добавлено
- Новая социальная сеть **Max** с настраиваемой ссылкой, заголовком и собственной PNG-иконкой (`assets/icons/icon-max.png`)
- Интеграция с **Яндекс.Метрикой**:
  - Поле для ввода номера счётчика в настройках плагина
  - Индивидуальные идентификаторы целей (Goal ID) для каждой кнопки (WhatsApp, Telegram, Viber, Max, Заказать звонок, Написать сообщение, Оставить отзыв)
- Динамическое формирование атрибута `onclick` – если номер счётчика не указан, события не отправляются
- Добавлен `onclick` для кнопок обратной связи (ранее отсутствовал)
- Вспомогательный метод `build_onclick()` для гибкой генерации JavaScript-вызовов

### Улучшено
- Убран жёстко прописанный номер счётчика и цели из HTML-кода – теперь все настраивается через админ-панель
- Улучшена безопасность: данные экранируются через `esc_js()` и `intval()`
- Исправлено выделение кнопок при клике (фокус) – добавлены CSS-правила `:focus { outline: none; box-shadow: none; }`

### Изменено
- Версия плагина обновлена до 1.4.0
- Реструктурирован код для лучшей поддерживаемости
