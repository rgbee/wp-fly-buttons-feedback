# Changelog

## [1.2.1] - 2025-11-12

### Исправлено
- Корректная работа переводов в админ-панели
- Исправлен текстовый домен во всех функциях перевода
- Убрана отладочная информация

## [1.2.0] - 2025-11-12

### Добавлено
- Локальная версия Font Awesome 6.2.1
- Автоматическое создание папок при активации плагина
- Fallback на CDN если локальные файлы отсутствуют

### Изменено
- Улучшена производительность за счет локальных ресурсов
- Увеличена надежность (не зависит от CDN)

## [1.1.0] - 2025-11-12

### Добавлено
- Расширенные настройки для кнопок обратной связи
- Возможность включения/выключения отдельных кнопок
- Настройка заголовков, ссылок и атрибутов для каждой кнопки
- Индивидуальные цвета для кнопок обратной связи
- Кастомные CSS классы

### Изменено
- Улучшена структура кода
- Оптимизированы стили
- Добавлено отсутствие подчеркивания ссылок

## [1.0.0] - 2025-11-12

### Релиз
- Базовые кнопки социальных сетей (WhatsApp, Telegram, Viber)
- Базовая стилизация и цвета
- Адаптивный дизайн
- Настройки в админ-панели
